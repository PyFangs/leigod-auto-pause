# 使用说明

## 首次运行

下载 Releases 中的 Windows x64 ZIP，解压，打开“雷神自动暂停助手.exe”。不用在助手中登录雷神、Steam 或任何账号；它使用已经安装在电脑上的客户端。

新的用户配置没有预置游戏，默认自动添加本机 Steam 游戏。首次打开时，为注册具有足够权限的开机后台任务，程序会通过 Windows 正常的 UAC 流程请求管理员权限；已经有管理员权限时直接完成。确认后自动开启开机运行，主窗口保持可见，方便首次设置；不会在首次打开时自动缩到托盘。取消后仍可进入程序，之后可在设置中重试，不会反复弹出同一个请求。

请使用自己信任的 Windows 管理员账号完成权限确认。程序不能代替或绕过 Windows 权限确认。

## 日常使用

1. 在雷神中开始游戏加速，再启动游戏。
2. 游戏真正运行过并退出后，助手按设置的秒数等待，再显示“是否暂停雷神的计费时长”。
3. 点击“暂停时长”，助手检查游戏是否重启、加速对象是否变更，再通过雷神界面暂停。
4. 点击“继续加速”、关掉提醒或不选择，都不会暂停。

游戏在倒计时或提醒期间重启，会取消旧提醒。退出等待为 0 秒时，是在下一次检测到退出时询问，仍须确认，不会直接暂停。多个被识别的加速游戏同时运行时，要等它们全部退出；有未识别的加速游戏时会阻止全局暂停。

雷神可以最小化到托盘。必要时助手会尝试用雷神自身的窗口恢复方式唤回主窗口，等待可识别的按钮出现再操作。成功只更新状态和记录；失败、无法恢复窗口或无法确认暂停结果才提示。右上角显示“开启时长”且时间不再跳动，表示暂停。

## 主窗口与托盘

主页面只显示已添加游戏，包括监控开关、游戏名称和状态。取消勾选立即停用该游戏的监控。右键游戏可移除，移除后不会自动重新加入；再次主动添加可以恢复。

首次点击“×”时会弹出一次说明，告知助手会继续在托盘监控、双击图标可重新打开、右键“退出”才真正结束。之后不重复打扰。关闭主窗口会继续后台监控。从托盘菜单选择“退出”才真正结束程序。托盘还可打开设置或手动请求暂停时长；手动暂停也必须确认。

## 添加游戏

自动发现依据 Steam 安装清单和雷神本地启动信息，不是按整块硬盘递归搜索。搜索框支持游戏名、Steam 编号、安装路径或已知别名。选中游戏后可直接添加，无需填写进程名。

找不到时，点击“手动添加游戏”：选中列表项时默认打开该游戏的安装目录，否则默认打开 Steam 的 steamapps/common。可以自行切换到其他盘、其他平台或任意安装位置，选择游戏主程序 .exe，再确认雷神中显示的游戏名称。

不要选择 Steam、游戏启动器、崩溃报告或卸载程序。助手会排除常见辅助程序。手动选择会按实际完整程序路径绑定；同名 .exe 出现在其他文件夹不会被当成这个游戏。选择其他 Steam 库内的程序时会记住对应库，以便后续发现。

雷神缓存里有明确且有效的本地启动程序路径时，非 Steam 游戏也可自动加入。名称关联仍需要匹配雷神显示的加速游戏。

## 设置

- 自动添加本机游戏：打开后定期读取安装信息；关闭后保留现有游戏列表。
- 开机后在后台运行：首次默认启用，可以主动关闭。之后打开程序不会强制重新启用。
- 退出等待：0–600 秒，修改立即保存。
- 高级设置：更换雷神启动程序路径。
- 诊断信息：查看本地状态和记录，排错时使用。

旧用户升级保留原配置，包括退出等待、禁用或移除记录和已有的程序绑定。旧 DOTA2 配置与任何其他手动进程配置使用相同规则，不存在特殊判断。

## 识别与故障

文字识别依赖 Windows 本地 OCR。字体、缩放、小字、窗口遮挡或游戏名被截断都可能影响识别，尤其是部分中文名称。显示有未识别加速游戏时，程序会停止自动暂停；这可能导致漏提醒，而不会猜测点击计费按钮。

如果缺少中文文字识别组件，按程序提示在 Windows 语言设置中补充简体中文组件。如果无法识别雷神按钮，确认主窗口可正常显示，并检查雷神版本、缩放或布局是否变化。如果退出没提醒，先确认游戏被勾选、主程序路径正确、确实运行过，以及当前加速游戏已经关联。

收到暂停失败提示时，检查雷神右上角是否显示“开启时长”且计时停止。如果仍显示“暂停时长”，请在雷神中手动处理。助手不会反复点击未确认的开关，也不会自动确认无法辨认的雷神二次弹窗。

不能保证所有游戏和所有雷神版本都能识别。使用者已验证 DOTA2 实际流程，通用测试结果见 testing.md；模拟客户端通过不等于其他游戏已实玩验证。

## 升级与卸载

已经启用开机运行时，推荐退出助手并覆盖原目录、原文件名的程序。不要在程序运行时覆盖它。换目录或文件名之前，在旧程序设置中关闭开机运行，再到新程序启用。

卸载时点击主窗口右下角“卸载”，阅读确认后选择继续；取消确认或 Windows 权限提示时，助手会继续运行。确认后移除属于当前程序的开机启动项，退出助手，删除当前助手程序、其说明/诊断文件，以及本地配置和记录。解压目录中的其他文件保留；只有已空的解压目录才会删除。任务以当前用户标识区分，多用户不会共享配置。

运行中的程序需要临时卸载进程处理文件锁定。临时进程由当前程序本身复制产生，不下载其他程序；核对 Windows 用户、原程序路径和文件哈希后再删除。临时卸载文件使用 Windows 正常的重启后清理机制处理，不执行远程脚本。若同名启动项指向另一位置、文件已变更或路径包含链接，会停止相关删除并提示。

配置、会话记录和确认请求主要保存在该本地目录；程序目录可能出现运行状态、恢复检查等本地诊断 JSON。分享时请直接使用官方本项目发布包，不要把个人运行目录整体打包。

## 下载校验

ZIP 的 SHA-256 列在 dist/SHA256SUMS，Release 同时提供该文本。可以用 Windows PowerShell 的 Get-FileHash 核对。校验能验证下载与发布文件一致，并不能独立证明代码安全。
