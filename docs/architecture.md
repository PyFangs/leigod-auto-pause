# 实现、权限与本地数据

## 监控流程

Discovery.cs 读取 Steam 注册信息、libraryfolders.vdf 和 appmanifest_*.acf，关联雷神本地 LevelDB 缓存中的游戏标题、Steam 启动编号和程序路径。解析只提取游戏启动信息，不提取账号密码、Cookie 或 Token，不写回 Steam 或雷神配置。

Models.cs 管理加速会话、进程开始/退出记录、等待时长、提醒和确认有效性。按完整程序路径或安装目录判断进程，排除常见启动器和报告程序。新增配置为空，各游戏遵循相同规则。

Client.cs 使用 Windows 自带 OCR，只识别雷神窗口的计费工具栏和加速列表区域。图像默认在内存中处理，日常使用不持续保存桌面截图。点击前检查目标窗口、桌面状态、计费按钮和会话；暂停后识别“开启时长”等状态确认结果。

Program.cs / FirstRunSetup.cs 处理单实例、正常提权、当前用户开机任务和本地配置。GuardForm.cs / ProductUi.cs / SteamLibraryPicker.cs 提供界面。

## 需要的权限

管理员权限用于监控和操作可能以管理员权限运行的雷神，以及注册开机任务。新用户确认一次 Windows 提示后，任务在下次登录时延迟约 8 秒启动后台监控。任务名为 LeigodGuard-加当前用户 SID，运行目标为助手自身的本地程序。

这是正常的 Windows 权限与计划任务机制，不关闭安全软件、不绕过 UAC、不改变系统安全设置。权限取消或操作失效时保留原计费状态，不能把沉默当成暂停许可。

## 会写入什么

`%LOCALAPPDATA%\LeigodGuard` 中包括 settings.json、sessions.jsonl、临时确认请求/结果和按需诊断文件。可能包含游戏名称、路径、运行/退出时间及错误信息。日志超过约 2 MB 后保留一次旧日志副本。

助手目录可能写入运行状态、恢复检查等 JSON，其中可能有当前用户配置目录、状态和游戏名称。卸载步骤见 usage.md。分发 ZIP 只包含程序与说明，不包含个人配置、日志或账号数据。

## 网络与程序修改

程序自身不建立网络连接、不遥测、不自动上传数据、不自动更新。没有第三方账号 API、远程脚本下载或账号登录模块；游戏库和启动信息来自本机。暂停使用正常的 GUI 输入，不注入进程、不读取或修改游戏内存，也不改写雷神/游戏程序文件。
