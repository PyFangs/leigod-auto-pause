# 雷神自动暂停助手 v2.4.0

- 首次打开保持主窗口可见，权限确认后不再自动缩到托盘，方便设置。
- 首次点击“×”会解释后台托盘行为，以及重新打开和退出的方法；说明只显示一次。
- 主窗口右下角新增小型“卸载”按钮，确认后移除助手的开机启动、当前程序和本地设置记录。
- 卸载核对同一 Windows 用户、当前程序文件哈希和启动项归属，保留安装目录中的其他文件；临时卸载文件在重启后清理。
- Windows 正常关机时结束助手，不拦截为“关闭到托盘”。
- 192 项检查通过：157 项状态、配置、界面和卸载边界检查，以及 35 项模拟客户端 OCR/实际测试进程生命周期/界面点击检查。

Windows 10/11 x64，下载 leigod-auto-pause-v2.4.0-win-x64.zip，解压运行“雷神自动暂停助手.exe”。新用户确认 Windows 权限提示后自动启用开机运行，主窗口仍保持可见。后续开机时后台监控，可在设置中关闭。

DOTA2 实际流程由使用者验证，其他游戏通过模拟通用流程测试，不代表逐款实玩。Windows OCR 对部分字体、小字和截断名称仍可能误识别，导致漏提醒；无法可靠关联时阻止自动暂停。

程序公开源码、不调用雷神账号接口、不上传个人数据、不注入游戏或雷神进程，没有代码签名或安全认证。分发包只含程序和说明，不带个人配置和记录。现有用户升级前，请从托盘退出旧版；若更换文件名或位置，先停用旧版开机启动。
