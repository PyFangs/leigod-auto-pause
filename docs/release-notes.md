# 雷神自动暂停助手 v2.3.0

Windows 10/11 x64，ZIP 解压即用。

- 退出确认窗口更紧凑，按钮等宽居中，键盘初始焦点为继续加速。
- 默认从 Steam 游戏目录手动添加游戏。
- 新用户首次运行自动请求所需权限并启用开机后台运行，旧配置保留。
- 主列表仅保留监控开关、游戏名称和运行状态。
- 167 项本地检查通过，包括三个非 DOTA2 名称的独立模拟客户端、实际测试进程退出/重启和 Windows OCR 点击确认。

DOTA2 已由使用者实际验证。其他游戏不是逐款实玩验证，Windows OCR 对部分中文字体、较小文字和截断名称可能识别不准，可能漏提醒。无法可靠关联时阻止自动暂停。

下载 leigod-auto-pause-v2.3.0-win-x64.zip，解压运行“雷神自动暂停助手.exe”。首次确认 Windows 权限提示后自动启用开机运行，可在设置中关闭。不需要在助手中登录账号。

公开源码、不调用雷神账号接口、不上传个人数据、不注入游戏或雷神进程。程序没有代码签名或安全认证；实现、数据、卸载和完整限制请看仓库说明。ZIP 仅含程序和说明，不包含个人配置或记录。
