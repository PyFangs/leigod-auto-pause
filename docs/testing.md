完整模拟测试使用 PUBG / APEX / PORTAL 三个名称作为界面样本，启动的是复制到临时目录的测试程序，分别覆盖两个安装目录绑定、一个非 Steam 精确路径绑定，以及 0、5、1 秒等待。不会启动这些真实游戏，也不会操作真实雷神账号或计费按钮。

DOTA2 实际流程由使用者使用数日验证，当前仍正常。这些通用测试不代表 PUBG、Apex、Portal 或所有其他游戏已实玩验证。首次权限测试以替代操作验证策略，没有自动接受真实 Windows UAC。

测试过程中观察到部分中文细字体或文字布局可被 Windows OCR 误识别；此限制仍存在，可能漏提醒。未关联游戏阻止全局暂停的保护有状态测试覆盖。此版本主要改进确认窗口布局，不宣称解决所有 OCR 字体兼容问题。

可自行运行 src/tests/run-tests.ps1；无前台桌面时使用 -SkipClientClickTest 会跳过 35 项 OCR 点击集成检查，其他 132 项仍运行。测试不携带真实用户配置。测试通过不等于零缺陷或所有客户端版本均兼容。
